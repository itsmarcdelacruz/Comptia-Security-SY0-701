# Contributing to the SY0-701 Study Guide 🛡️

First off, thank you for considering contributing! This resource is built by the community, for the community. To maintain a "Gold Standard" level of quality, please follow these guidelines.

---

## 🛠️ How Can You Help?
1.  **Add New Notes:** Fill in missing objectives from the CompTIA SY0-701 syllabus.
2.  **Fix Errors:** Spot a typo or a technical inaccuracy? Please correct it!
3.  **Refine Formatting:** Improve tables, add Mermaid diagrams, or suggest better "Exam Tips."
4.  **Update Acronyms/Ports:** Help keep our cheat sheets current.

---

## 📝 Style & Formatting Rules
To keep the guide consistent, please follow these rules:

### 1. Use the Template
Before creating a new note, copy the structure from `TEMPLATE.md`. This ensures every page has the same "look and feel."

### 2. High Scannability
* Use **Bold** for key terms.
* Use tables for comparisons.
* Use `> [!IMPORTANT]` for "Exam Tips."

### 3. Tone & Voice
* Keep it professional yet accessible. 
* Avoid "fluff"—focus on what is required for the exam objectives.
* If a concept is confusing, try to provide a "Real-World Scenario."

---

## 🚀 The Process
1.  **Search:** Check the [Issues](https://github.com/itsmarcdelacruz/Comptia-Security-SY0-701/issues) to see if someone is already working on that objective.
2.  **Fork:** Create your own copy of the repo.
3.  **Branch:** Create a branch for your work (e.g., `feature/domain-2.1-notes`).
4.  **Commit:** Use clear commit messages (e.g., `Add notes for Objective 2.1: Social Engineering`).
5.  **Pull Request:** Submit your PR! We will review it as soon as possible.

---

## ⚖️ A Note on Copyright
Please do not copy-paste directly from paid resources (Dion, Messer, Official CompTIA books). Summarize the concepts in your own words. This is a study guide, not a copyright infringement project!
