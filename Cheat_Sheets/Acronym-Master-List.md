# 📕 CompTIA Security+ SY0-701 Acronym Master List

> **Usage Tip:** Press `Ctrl + F` (or `Cmd + F`) to quickly search for an acronym while studying.

---

## 🏛️ General Concepts & Frameworks
| Acronym | Full Name | Context |
| :--- | :--- | :--- |
| **AAA** | Authentication, Authorization, Accounting | The core framework for access control. |
| **CIA** | Confidentiality, Integrity, Availability | The "Triad" of security goals. |
| **GAP** | Gap Analysis | Comparing actual performance with potential/desired performance. |
| **GRC** | Governance, Risk, and Compliance | The overarching strategy for managing an org's security. |
| **KPI** | Key Performance Indicator | A metric used to evaluate success. |
| **KRI** | Key Risk Indicator | A metric used to predict potential risks. |
| **MSSP** | Managed Security Service Provider | Outsourced security monitoring and management. |

---

## 🔐 Cryptography & Identity
| Acronym | Full Name | Context |
| :--- | :--- | :--- |
| **AES** | Advanced Encryption Standard | The gold standard for symmetric encryption. |
| **CA** | Certificate Authority | An entity that issues digital certificates. |
| **CSR** | Certificate Signing Request | A message sent to a CA to apply for a digital certificate. |
| **HSM** | Hardware Security Module | Physical device that manages digital keys. |
| **MFA** | Multi-Factor Authentication | Requiring 2+ types of evidence for identity. |
| **PKI** | Public Key Infrastructure | The system that manages digital certificates/keys. |
| **RSA** | Rivest, Shamir, & Adleman | A common asymmetric encryption algorithm. |
| **SAML** | Security Assertions Markup Language | XML-based standard for SSO (Single Sign-On). |

---

## 🌐 Networking & Infrastructure
| Acronym     | Full Name                               | Context                                                            |
| :---------- | :-------------------------------------- | :----------------------------------------------------------------- |
| **CASB**    | Cloud Access Security Broker            | Software/service between users and cloud apps to enforce security. |
| **DNSSEC**  | DNS Security Extensions                 | Adds digital signatures to DNS to prevent spoofing.                |
| **IDS/IPS** | Intrusion Detection/Prevention System   | Monitoring vs. actively blocking malicious traffic.                |
| **SDN**     | Software-Defined Networking             | Using software to manage network traffic.                          |
| **SIEM**    | Security Information & Event Management | Centralized logging and real-time analysis of security alerts.     |
| **SWG**     | Secure Web Gateway                      | Filters web traffic to protect users from web-based threats.       |
| **VPN**     | Virtual Private Network                 | Encrypted tunnel over a public network.                            |

---

## ☣️ Threats & Incident Response
| Acronym | Full Name | Context |
| :--- | :--- | :--- |
| **APT** | Advanced Persistent Threat | A prolonged, targeted attack (usually nation-state). |
| **BCP** | Business Continuity Plan | How to keep the business running during a disaster. |
| **CVE** | Common Vulnerabilities and Exposures | A list of publicly disclosed cybersecurity vulnerabilities. |
| **DRP** | Disaster Recovery Plan | How to restore IT systems after a disaster. |
| **IRP** | Incident Response Plan | The "Playbook" for when a breach occurs. |
| **MTTR** | Mean Time to Repair/Respond | A metric for how fast you fix/respond to issues. |
| **RAT** | Remote Access Trojan | Malware that gives an attacker control over a device. |
