# 🏷️ Common Ports & Protocols
*Memorizing these is mandatory for the Security+.*

| Port | Protocol | Description | Secure Version? |
| :--- | :--- | :--- | :--- |
| 20/21 | FTP | File Transfer | SFTP (22) or FTPS (990) |
| 22 | SSH | Secure Shell | (Already Secure) |
| 23 | Telnet | Remote Access | **Insecure** (Use SSH) |
| 25 | SMTP | Email Send | SMTPS (465 or 587) |
| 53 | DNS | Domain Name System | DNSSEC |
| 80 | HTTP | Web Traffic | HTTPS (443) |
| 3389 | RDP | Remote Desktop | Requires Gateway/VPN |
