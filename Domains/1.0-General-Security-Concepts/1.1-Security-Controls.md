# 1.1 Compare and Contrast Security Control Categories

> **Exam Domain:** 1.0 General Security Concepts  
> **Status:** 🟢 Complete

---

## 🔍 Core Concepts
Security controls are the safeguards or countermeasures used to avoid, detect, counteract, or minimize security risks. CompTIA categorizes these in two ways: by **Category** (how they are implemented) and by **Type** (what they act to do).

### 1. Control Categories (The "How")
These define the nature of the control's implementation.

* **Technical (Logical):** Controls implemented via systems (hardware, software, firmware).
    * *Examples:* Firewalls, Encryption, Antivirus, MFA.
* **Managerial (Administrative):** Controls that guide the "people" and business processes.
    * *Examples:* Security policies, Employee training, Onboarding/Offboarding processes.
* **Physical:** Controls you can physically touch that protect the environment.
    * *Examples:* Fences, Door locks, CCTV, Security guards, Lighting.

### 2. Control Types (The "What")
These define the functional purpose of the control.

| Type | Purpose | Example |
| :--- | :--- | :--- |
| **Preventative** | Stops an incident before it happens | Firewall rule, Physical lock |
| **Detective** | Identifies an incident during or after it occurs | Motion sensor, Log review, IDS |
| **Corrective** | Reverses the impact of an incident | Backups, Patching a system |
| **Deterrent** | Discourages an attacker from attempting | "Warning" signs, Fake cameras |
| **Compensating** | A "Plan B" when the primary control is too expensive/complex | Using a sandbox because you can't patch an old app |
| **Directive** | Mandatory rules (legal or policy) | Acceptable Use Policy (AUP) |

---

## 📊 Comparison: Categorizing a Single Asset
To understand these, look at how one "goal" (like stopping unauthorized entry) can be met by different categories:

| Category | Control Implementation |
| :--- | :--- |
| **Technical** | A smart-card reader at the front door. |
| **Managerial** | A policy stating all visitors must wear badges. |
| **Physical** | A 10-foot barbed wire fence around the building. |

---

## 🔑 Key Acronyms
| Acronym | Full Name | Description |
| :--- | :--- | :--- |
| **AUP** | Acceptable Use Policy | Defines how employees may use company resources. |
| **IDS** | Intrusion Detection System | A detective technical control for network traffic. |
| **MFA** | Multi-Factor Authentication | A technical preventative control for identity. |

---

## 💡 Exam Tip
> [!IMPORTANT]
> **CompTIA Mindset:** If a question asks for the "most cost-effective" way to reduce risk, the answer is almost always **Managerial/Administrative** (like User Training). If it asks how to stop a "specific technical exploit," look for a **Technical** control.

---

## 🏁 Quick Knowledge Check
**Scenario:** A company installs a CCTV camera to record people entering the server room. What **Category** and **Type** of control is this?
* *Answer:* **Physical** (Category) and **Detective** (Type).
